# Ogma – Educational Module Discovery Platform

## Overview

Ogma is a **web-based educational platform** developed as part of a **team university project**, designed to help users discover, explore, and interact with academic modules in a more organized and user-friendly way.

The application allows users to browse available modules, filter and search through course-related data, view lecturers and events, enroll in modules, leave reviews, and manage relevant academic information through an integrated interface.

The project was built using **ASP.NET MVC** and aimed to simulate a more realistic software product with both front-end and backend functionality, database integration, and deployment to an **Azure server**.

---

## Purpose

The purpose of Ogma was to create a structured educational web application that supports:

- **module discovery and search**
- **faceted filtering**
- **user enrollment workflows**
- **event and lecturer browsing**
- and **calendar-based academic organization**

The project was also intended to provide hands-on experience with:

- **ASP.NET MVC architecture**
- **database-driven application development**
- **team collaboration**
- and **deployment in a cloud environment**

## Features

- User **register / login**
- Browse and view academic **modules**
- **Search bar** functionality using Lucene.Net
- **Faceted filtering** by:
  - category
  - lecturer
  - event date
  - duration
- View **module information** and related **events**
- Browse **lecturer information**
- **Enroll / Buy** functionality for modules
- Email notification after enrollment
- Submit **reviews** for events/modules
- Personalized **MyCalendar** view for enrolled modules
- Google Calendar integration for selected academic events

---

## Database Functionality

The project includes a MySQL database designed to support:

- academic modules
- lecturers
- events (labs / lectures)
- reviews
- enrollments
- filtering relationships between data

The database was designed, populated, tested, and connected to the application to support both search and calendar functionality.
